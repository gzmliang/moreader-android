## 2. UI 交互与视觉规范（全屏沉浸大弹窗）

遵循梁老师拍板的 **方案 1（全屏沉浸展示）**：
1. **唤起入口**：
   - 阅读器顶栏/菜单右侧新增精致按钮：`🤖 AI 伴读`（英文环境显示 `🤖 AI Companion`）；
   - 书架顶栏右上角设置菜单内新增 `🤖 AI Settings` 入口。
2. **容器与布局**：
   - 采用全屏模态页面（Full-screen Dialog / Overlay），背景支持日间白底与夜间暗黑主题；
   - **顶栏导航**：
     - 左侧：`←` 返回按钮（回到阅读器） + 当前书籍名与章节名（自适应省略）；
     - 中部：4 个清晰 Tab（`📚 简读`、`🕸️ 图谱`、`✍️ 自测`、`📊 战报`）；
     - 右侧：`A- / A+` 动态字号缩放按钮 + `⚙️` AI 设置快捷入口 + `✕` 关闭按钮。
3. **视觉要求**：
   - 适配普通手机窄屏与 E-Ink 墨水屏（高对比度，黑白分明，无刺眼动画）；
   - 弹窗内容区最大利用屏幕可视面积，各 Tab 支持顺畅垂直滚动。

## 3. AI Provider 统一设置中心架构

遵循梁老师“方案 A 统一聚合”与“对齐读伴”规范：
1. **预设提供商 (Preset Providers)**：
   - `OpenAI`：`https://api.openai.com/v1`（默认模型 `gpt-4o-mini`）
   - `DeepSeek`：`https://api.deepseek.com/v1`（默认模型 `deepseek-chat`）
   - `SiliconFlow (硅基流动)`：`https://api.siliconflow.cn/v1`（默认模型 `Qwen/Qwen2.5-7B-Instruct`）
   - `OpenRouter`：`https://openrouter.ai/api/v1`（默认模型 `anthropic/claude-3.5-haiku`）
   - `Custom (自定义)`：用户可全自由输入 Base URL、Model 与自定义 Headers。
2. **字段管理**：
   - `Base URL`（自动补齐/去除尾部多余 `/` 与 `/chat/completions`）；
   - `API Key`（安全存储，界面带掩码切换）；
   - `Model Name`（允许手动自由输入）；
   - `源语言 (Source Language)` 与 `目标语言 (Target Language)`（默认英文 ➔ 简体中文）；
   - **操作按钮**：`⚡ 测试连接`（带翠绿成功/明红失败反馈）与 `💾 保存配置`。
3. **无缝拦截引导**：
   - 用户首次点击 AI 伴读功能若未配置 API Key，弹出温馨引导弹窗，一键跳转到配置页，配完即用。

## 4. E-Ink 墨水屏深度专项优化规范（极致黑白与零残影）

针对文石、掌阅、海信等墨水屏设备的低刷新率、容易产生残影以及灰阶表现弱的物理特性，系统内置深度专项优化：

1. **一键开启与状态持久化**：
   - 在 AI 伴读界面顶栏常驻 **`🖤 墨水屏模式 (E-Ink Mode)`** 快捷开关；
   - 开启后偏好保存在本地配置，全局与会话间自动保持。
2. **极致高对比度（Pure Black & White）**：
   - **底色与文字**：背景为纯白（`#FFFFFF`），所有正文、标题均为纯黑（`#000000`），彻底禁用半透明浅灰、模糊阴影和彩色蒙层；
   - **边框与分隔**：所有卡片容器、选项框、表格均采用 **`1dp / 2dp 纯黑或深灰实线边框`**，边界清晰锐利；
   - **做题选项**：未选中为清晰空心圈 `○`，选中为纯黑实心 `●`，答对加粗实线带实心勾 `✓`，错题加粗显示 `✗`，不依赖颜色区分。
3. **零动画与防残影（Zero-Animation Snap）**：
   - 在开启墨水屏模式时，彻底禁用 Tab 切换平移动画、弹窗淡入淡出、折叠展开平滑动画；
   - 全部改为 **瞬时无延迟切换（Instant Snap）**，大幅减少墨水屏刷新时的闪烁和残影。
4. **字体字重与排版强化（Typography for E-Ink）**：
   - 默认采用 Medium / SemiBold 加粗字重，防止墨水屏颗粒吃掉细笔画；
   - 双语对照垂直行距保持 1.6 倍以上，段落间留出舒适黑白呼吸感；
   - `A- / A+` 动态字号阶梯式增大，让大字版阅读在墨水屏上尤为舒适。

## 5. 核心功能详细规范

### 4.1 提炼简写本 (Summary)
* **参数配置栏**：
  - **浓缩比例**：自由数值输入（10% ~ 80%，默认 30%）；
  - **提炼范围**：`当前章节 (Current Chapter)` vs `全书宏观 (Entire Book)`；
  - **语言排版三挡切换**：
    - `🔄 双语对照 (Bilingual)`：严格按“首行原文、换行次行中文译文”对齐分层排版；
    - `📄 仅原著 (Original Only)`：纯外语，适合精细研读磨耳朵；
    - `🌐 仅译文 (Translation Only)`：纯中文，适合快速理解大意。
* **智能字号缩放**：
  - 支持 `A- / A+` 动态缩放（14sp ~ 24sp），设置持久化，跨会话记忆。
* **Markdown 典雅渲染**：
  - 核心观点、分幕小标题、引用块（左侧亮条）分层呈现，Emoji 清晰保留。

### 4.2 人物与情节图谱 (Character & Plot Map)
* **一、叙事格局与推进核心**：一句话概括本章或全书核心冲突与世界观；
* **二、人物关系网络 (Relationship Cards)**：
  - 自适应流式卡片（`FlowRow` / 卡片网格）；
  - 清晰展示角色名字、所属家族/阵营徽标、以及角色之间关系（如：依附、同盟、宿敌）；
* **三、关键情节推进线 (Plot Timeline)**：
  - 起因 ➔ 冲突/转折 ➔ 结果/伏笔 垂直时间轴排版；
  - 同样遵循双语/仅原文/仅译文三挡排版规则。

### 4.3 章节自测闯关 (Quiz)
* **参数选择**：
  - 题数：3 题 / 5 题 / 10 题；
  - 难度：基础理解 (Basic) / 深度情节 (Intermediate) / 主旨与思辨 (Advanced)；
* **双反馈模式**：
  - **模式 A：即时揭晓 (Instant)**：
    - 读者点选选项瞬间给出翠绿 `✓` 或红色 `✗`，展开小聪名师中英文深度解析；
  - **模式 B：完卷提交 (On Submit)**：
    - 点击选项只点亮选中状态，不剧透对错，允许反复修改；
    - 底部显示 `📝 提交全卷并查看得分`，点击后统一揭晓成绩、错题与解析。

### 4.4 答题成绩单与逐题复盘 (History & Reports)
* **战报列表**：
  - 记录每次自测的时间、章节、得分率（如 `5/5 100% 🏆`）、难度模式；
* **逐题复盘详情**：
  - 点击任意历史记录展开：复盘每一道题的原题、读者当时选的选项、标准答案及解析。

## 6. 深度结合功能：原生听精读与一键存入书架

### 5.1 面板内“▶ 听精读”
* **控制条**：简读本顶部右上角常驻 `▶ 听精读` / `⏸ 暂停` 迷你控制条；
* **三种朗读模式（遵照梁老师讨论第 6 点要求）**：
  - `只听原文`：适合外语磨耳朵；
  - `只听译文`：适合快速扫听吸收；
  - `双语穿插`：读一句原文、读一句中文译文，精学研读；
* **引擎联动**：直接复用项目中现有的 `EdgeTTSProvider`，保障真人般高保真发音与语速调节。

### 5.2 “📚 存入书架”规范（遵照梁老师讨论第 7 点要求）
* **命名规范**：
  - 单章生成：《`原书名` - Ch.`X` (精读速览)》；
  - 全书生成：《`原书名` (全书精读版)》；
* **书架集成**：
  - 自动生成轻量 EPUB 文件存入 App 内部私有目录；
  - 在书架数据库中自动生成书籍条目，封面附带亮眼徽标 `AI 精读`；
  - 用户在书架点击后直接像看正常书一样翻页阅读，并能无缝调用系统/Edge-TTS 完整朗读。

## 7. 数据流与本地缓存生命周期设计

* **严格强隔离生命周期（彻底根除跨书串味）**：
  - 缓存 Key 格式：`ai_cache_{bookId}_{chapterIndex}_{scope}_{ratio}`；
  - 用户切换书籍或关闭阅读器时，**第一时间无条件重置当前内存 ViewModel 状态**；
  - 只有确认当前正在看的书籍 ID 与章节索引与缓存匹配，才亮起 `⚡ Cached` 绿标直接秒级回显；
* **零 Token 重复消耗**：
  - 同一章节同一比例生成过一次后，退出再进直接秒开，绝不重复调用网络请求。

## 8. 国际化与防硬编码红线规范

🚨 **最高铁律**：除畅说特例，本项目界面严禁硬编码中文！
- 所有新增字符串统一在两处维护：
  1. `app/src/main/res/values/strings.xml`（中文简体）；
  2. `app/src/main/res/values-en/strings.xml`（英文出海）；
- 所有 Compose UI 必须通过 `stringResource(R.string.xxx)` 读取。
- **品牌名称规范**：彻底移除“墨阅”，全局统一为 **`Moreader`**。
